# یادگیری کامپیوتر گرافیکی به سبک تِرِد

تِرِد ها پست های کوتاه با هدف بیان یک ایده به سریع ترین حالت ممکن هستند... حالا اگر هر مطلب آموزشی رو به شکلی ریز ریز کنیم که بتونیم در واحد های اولیه ای به عنوان تِرِد آموزششون بدیم میتونیم مخاطب رو خسته نکنیم و از این قضیه برای آموزش هر مطلبی به شکلی بهتر استفاده کنیم...

این دوره از تمپلیت [NBT Theme](https://github.com/The-CS12/ntb-theme) استفاده میکنه که دوست عزیزم فَرِهان درستش کرده.


### نحوه مشارکت یا اعلام مشکل
پروژه کاملا Open-source هستش و در صورت مواجهه با هرگونه ایراد در محتوای آموزشی, غلط املایی و یا حتی مشکل علمی محتوا میتونید **Issue** باز کنید.

و میتونید خودتون هم توی ایجاد تِرِد ها مشارکت کنید!
