بیاید از ساده‌ترین چیزی که می‌تونیم توی یک دنیای گرافیکی داشته باشیم شروع کنیم:

**یک نقطه.**

فرض کنید می‌خوایم یک نقطه روی صفحه داشته باشیم.

کامپیوتر از کجا باید بفهمه این نقطه دقیقا کجاست؟

مثلا اینجا؟

یا اینجا؟

یا یک جای دیگه؟

برای اینکه بتونیم موقعیت یک نقطه رو مشخص کنیم، به یک روش برای **اندازه‌گیری موقعیت** نیاز داریم.

اینجاست که **Coordinate** ها وارد ماجرا می‌شن.

---

{{< readmore type="" title="Coordinate یعنی چی؟" open="false" >}}

برای مشخص کردن موقعیت یک نقطه، معمولاً از چند عدد استفاده می‌کنیم.

در یک صفحه‌ی دوبعدی، می‌تونیم موقعیت یک نقطه رو با دو عدد مشخص کنیم:

**X** : موقعیت افقی

**Y** : موقعیت عمودی

:

```
Point = (3, 2)
```

یعنی نقطه‌ی ما در موقعیتی قرار گرفته که:

* مقدار X آن برابر 3 است.
* مقدار Y آن برابر 2 است.

به این اعداد **Coordinates** یا مختصات می‌گیم.

{{< /readmore >}}

---

### Origin کجاست؟

برای اینکه مختصات معنی داشته باشن، باید یک نقطه‌ی مرجع داشته باشیم.

به این نقطه می‌گیم:

**Origin**

و مختصاتش اینه:

```
(0, 0)
```

از این نقطه می‌تونیم موقعیت بقیه‌ی نقاط رو مشخص کنیم.

مثلاً:

<img src="/assets/static-pic/threads/(3,2)-point-thick.png" style="width: 50%;">

حالا می‌دونیم نقطه‌ی `(3,2)` نسبت به Origin کجا قرار گرفته.

---

### خب، تو دنیای سه‌ بعدی چی؟

ما یک **فضای سه ‌بعدی** داریم.

پس برای مشخص کردن موقعیت یک نقطه، به یک بُعد دیگه هم نیاز داریم:

**Z**

بنابراین موقعیت یک نقطه‌ی سه‌بعدی می‌تونه به شکل زیر نمایش داده بشه:

```
(x, y, z)
```

مثلاً:

```
(3, 2, 5)
```

یعنی موقعیت این نقطه در فضای سه‌بعدی با سه مقدار مشخص شده.

---

{{< readmore type="" title="Coordinate System چیه؟" open="false" >}}

تا اینجا گفتیم:

* X موقعیت، روی یک محور رو مشخص می‌کنه.
* Y موقعیت، روی محور دوم رو مشخص می‌کنه.
* Z هم در فضای سه‌بعدی وارد می‌شه.
* یک Origin هم داریم.

مجموعه‌ی این قواعد، یک **Coordinate System** یا سیستم مختصات رو تشکیل می‌ده.

یعنی مشخص می‌کنیم:

> **مبدأ کجاست؟**

> **محورها کدوم هستن؟**

> **جهت هر محور چیه؟**

بعد می‌تونیم موقعیت نقاط مختلف رو نسبت به این سیستم مشخص کنیم.

{{< /readmore >}}

---

### پس تا اینجا چی داریم؟

اگر بخوایم یک دنیای سه‌بعدی خیلی ساده بسازیم، می‌تونیم با همین ایده شروع کنیم:

**Point → Position → Coordinates**

مثلاً:

```
Point A = (1, 2, 3)
Point B = (4, 1, 2)
Point C = (2, 5, 1)
```

و حالا اگر این نقاط رو به هم وصل کنیم، کم‌کم می‌تونیم شکل‌های هندسی بسازیم.

اما یک سؤال جدید داریم:

> **اگر بخوایم بجز موقعیت... جهت، طول و حرکت رو هم نمایش بدیم، چی؟**
