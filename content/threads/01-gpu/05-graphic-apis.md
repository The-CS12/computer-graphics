> **چه API های گرافیکی ای وجود دارن؟**

احتمالاً اسم این چهارتا رو شنیدین:

* **OpenGL**
* **Vulkan**
* **DirectX**
* **Metal**

بیاید خیلی سریع باهاشون آشنا بشیم.

---

{{< readmore type="" title="OpenGL" open="false" >}}

**OpenGL** توسعه یافته توسط Khronos Group، یکی از قدیمی‌ترین و شناخته‌شده‌ترین Graphics API هاست.  

یک API چندسکویی(کراس پلتفورم) که برای پیاده‌سازی Graphics استفاده می‌شه و در طول سال‌ها به یکی از API های مهم این حوزه تبدیل شده.

ما هم در بخش عملی این دوره از **OpenGL** استفاده می‌کنیم.

{{< /readmore >}}

---

{{< readmore type="" title="Vulkan" open="false" >}}

**Vulkan** توسعه یافته توسط Khronos Group، یک Graphics API مدرن، کراس پلتفورم و Low-level هست که کنترل بیشتری روی نحوه‌ی استفاده از GPU در اختیار برنامه‌نویس قرار می‌ده.

در عوض، کار کردن باهاش نسبت به API هایی مثل OpenGL پیچیده‌تره.

{{< /readmore >}}

---

{{< readmore type="" title="DirectX" open="false" >}}

DirectX یک API ساخته شده توسط مایکروسافته.

این API به‌خصوص در توسعه‌ی بازی‌ها و نرم‌افزارهای گرافیکی داخل اکوسیستم مایکروسافت، مثل Xbox و Windows استفاده‌ی زیادی داره.

{{< /readmore >}}

---

{{< readmore type="" title="Metal" open="false" >}}

**Metal** یک API ساخته شده توسط اپله که برای دسترسی به قابلیت‌های گرافیکی و محاسباتی GPU در دستگاه‌های Apple طراحی شده.

{{< /readmore >}}

### یک نکته مهم

این API ها **خودِ مبحث Computer Graphics نیستن.**

**Graphics** یک حوزه‌ی بزرگ از علوم کامپیوتره که درباره‌ی تولید، پردازش و نمایش تصاویر و صحنه‌های بصری صحبت می‌کنه.

Graphics API ها فقط ابزارهایی هستن که به ما اجازه می‌دن این مفاهیم رو روی کامپیوتر **پیاده‌سازی** کنیم.

پس در این دوره:

**Computer Graphics = چیزی که می‌خوایم یاد بگیریم**

**OpenGL = ابزاری که باهاش چیزهایی که یاد گرفتیم رو پیاده‌سازی می‌کنیم**
